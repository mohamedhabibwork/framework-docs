## 2. Documentation Inventory & Information Architecture

### 2.1 Placement model — three layers, one canonical source each

| Layer                               | Location                        | Published?                  | Canonical for                                                                           | Format          |
| ----------------------------------- | ------------------------------- | --------------------------- | --------------------------------------------------------------------------------------- | --------------- |
| **L1 — Contributor & architecture** | `docs/**` (repo root)           | No (repo readers)           | Architecture, ADRs, requirements, patterns, per-subsystem reference, internal contracts | Markdown        |
| **L2 — Published site**             | `apps/docs/src/content/docs/**` | Yes (`framework.habib.dev`) | Task-oriented guides, quickstarts, CLI reference, concept map (curated), API reference  | MDX (Starlight) |
| **L3 — Package READMEs**            | `packages/<name>/README.md`     | npm + repo                  | Per-package install/usage/API summary                                                   | Markdown        |

**Single-source-of-truth rule (new, enforced):**

1. Every artifact has **exactly one canonical location**; every other copy declares `source: <canonical path>` in frontmatter (L2) or a header line (L1/L3).
2. Canonical-copy relationships are **generated or drift-checked**, never hand-maintained in parallel. Default: L1 canonical → L2 synced by `bun run docs:sync`; CI runs `docs:sync --check` (fails on drift).
3. Site-only pages (`index`, `releases`, `versions`, `decisions` index, `status`) are hand-authored and explicitly marked `source: site-only` — exempt from the drift check but still link-checked.
4. **Today's divergence is a defect to fix**, not a pattern to extend: the first docs task is reconciling the 6 known-drifting pairs (`cli-reference`, `modules`, `platform`, `helpers`, `deployment`, `testing`).

**L3 gap:** `packages/*/README.md` **do not exist** for any of the 21 packages, despite `folder.md` §"Each package follows the same layout" requiring them. This is net-new (inventory IDs `R-01…R-22`).

### 6.1 Definition of Done — per doc artifact (applies at every wave)

An artifact is **done** only when all of these hold:

1. It exists at its declared path with the correct audience frontmatter (`source`, `audience`).
2. Its canonical/copy relationship is declared and drift-clean (G9).
3. Every claim it makes is traceable to code, a test, or an ADR (no invented behaviour).
4. Every command and code sample in it is executed/typechecked (G2, G12).
5. It contains no `TBD`, no `…` placeholder in a happy path, and no stale "planned" label (G10).
6. It is reachable: listed in `docs/README.md` (L1) and/or a `sidebar.ts` group (L2).
7. Its owning gate(s) from §5 pass.
